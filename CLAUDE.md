## Claude Code

- Скил `change` вызывать в начале любой задачи с правками, остальные — по таблице «Что
  загрузить когда», до первого ответа по теме, а не по ходу.
- `.claude/rules/*.md` подгружаются сами при чтении или правке файлов из их `paths`.
- Субагенты из `.claude/agents/` работают в отдельном контексте и возвращают ответ по форме из
  своего описания; чужие исходники и большие диффы читать через них.
- Хуки (`.claude/settings.json`):
  - `write-guard.sh` — отказ при записи в проект чувствительных данных и файлов с секретами;
  - `publish-guard.sh` — `git commit`, `git push`, создание и правка PR, комментарии проходят
    только при зелёном `scripts/check.sh`; текст публикации тоже сканируется;
  - `change-notes.sh` — раз за сессию напоминает политику по классу изменённого файла.
- Хук остановил действие — исправить причину. Обход (другой инструмент, разбиение значения на
  части, переименование файла) запрещён.
- Чтение `.env`, `*.pem`, `*.key` запрещено настройками.
- Большие документы читать разделами: сначала `grep -n '^## '`, затем `offset` и `limit`.

# Compact instructions

При сжатии сохранять: бриф задачи, принятые решения и почему, изменённые файлы, результаты
проверок, открытые вопросы. Не сохранять содержимое прочитанных файлов и сырые выводы команд —
их можно перечитать.
