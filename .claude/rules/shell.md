# Скрипты на Bash

- Bash — только для загрузчика, проверок репозитория и хуков; логика продукта пишется на Go.
- Переменные — в кавычках; команды — без `eval`; данные из сети и ввода не становятся кодом.
- `install.sh` идёт под `set -euo pipefail`, тело — в функции, вызываемой последней строкой.
- `scripts/check.sh` печатает только провалы и итог `checks: PASS|FAIL`; отсутствие нужной
  утилиты — провал, а не пропуск.
- `scripts/guard.sh` не имеет списков исключений: найденное убирается из текста; находка
  печатается под маской.
- Блокирующий хук завершается кодом 2 с причиной в stderr; вход читается через `jq`.
- Поведение скрипта или хука меняется — сценарий в `tests/test-guards.sh`, который без правки
  падает.
- После правки — `bash scripts/check.sh`.
