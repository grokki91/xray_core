# Скрипты на Bash и PowerShell

- Bash — только для загрузчика, проверок репозитория, хуков и каркаса проверки на реальной
  интеграции для VPS; логика продукта пишется на Go. PowerShell — только `scripts/integration/win11.ps1`.
- Переменные — в кавычках; команды — без `eval`; данные из сети и ввода не становятся кодом.
- `install.sh` идёт под `set -euo pipefail`, тело — в функции, вызываемой последней строкой.
- `scripts/check.sh` печатает только провалы и итог `checks: PASS|FAIL`; отсутствие нужной
  утилиты — провал, а не пропуск.
- `scripts/guard.sh` не имеет списков исключений: найденное убирается из текста; находка
  печатается под маской.
- Блокирующий хук завершается кодом 2 с причиной в stderr; вход читается через `jq`.
- Поведение скрипта или хука меняется — сценарий в `tests/test-*.sh` (сканер и хуки —
  `tests/test-guards.sh`), который без правки падает.
- `scripts/integration/` — каркасы, которые владелец запускает у себя: вывод — одна строка, уборка
  при любом исходе, чужие пакеты и рабочая установка не трогаются (`docs/dev/integration-check.md` §3).
- После правки — `bash scripts/check.sh`.
