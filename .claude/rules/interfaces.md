# Интерфейсы и контракт

Описание — `docs/architecture/interfaces.md`; меняется в той же правке, что и код.

- Адаптер не содержит логики: разобрать ввод, проверить, вызвать `app`, показать результат.
- Новая команда — только если действие не выражается флагом существующей.
- Машинный вывод — типы `contract`: новое поле — `minor + 1`; удаление, переименование, смена
  смысла — `major + 1` и ADR. Эталон схемы обновляется осознанно.
- Секрет печатают только команды, чьё назначение — его показать; `bridge` секретов и адресов
  не выводит никогда.
- Разрушительное действие требует явного флага и подтверждения.
- HTTP API слушает только петлю; у каждого запроса проверяются сессия, `Host` и `Origin`;
  эндпоинтов с произвольными командами и путями нет.
- Панель: без фреймворков, сборки и внешних ресурсов; данные в страницу — только `textContent`.
- Строки из журналов и сети — недоверенные: в терминал без управляющих последовательностей.
- Изменение API и панели — повод для субагента `security-reviewer`.
