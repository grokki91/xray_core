# Конфигурация Xray

- Отрисовка детерминирована: одно состояние — побайтно один файл; порядок ключей и элементов
  фиксирован.
- На каждый пресет — эталонный файл; каждый эталон проходит `xray run -test` на границах
  проверенного диапазона версий (`docs/testing.md`, уровень L3).
- Поля и значения по умолчанию upstream не угадываются: сверка по скилу `xray-upstream`, факт с
  датой — в `docs/compatibility.md`.
- В любом пресете обязательны: запрет частных, петлевых и link-local адресов назначения
  (`docs/security/policy.md` §4); выключенный журнал доступа; API Xray только на петле и только
  со статистикой.
- Фикстуры и эталоны — только с фиктивными значениями (`docs/security/secrets.md` §4); ключи
  в тестах создаются во время теста.
- Новый пресет — отдельный файл в `preset/`, поддержка в экспортёрах и строки в таблице
  совместимости в одной правке; выбор пресета пользователю не усложняется.
- Конфигурация пишется на диск только транзакцией `app`; прямой записи нет.
