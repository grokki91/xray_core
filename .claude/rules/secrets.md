# Секреты в коде

Политика — `docs/security/secrets.md`; здесь — что из неё следует при правке этих пакетов.

- Случайные секреты создаёт только `security`, только из `crypto/rand`; значений по умолчанию
  и «временных» ключей нет.
- Секрет не попадает в журнал, текст ошибки, аргументы процесса и переменные окружения — на
  любом уровне подробности.
- Всё, что уходит человеку или в файл вне манифеста прав, проходит `redact`; новый вид
  секрета регистрируется в редакторе в той же правке.
- Файлы с секретами создаются сразу с правами по манифесту
  (`docs/architecture/data-model.md` §1), а не исправляются после записи.
- Сравнение секретов — за постоянное время.
- Снимок содержит секреты и не покидает VPS; архив читается с проверкой путей и размеров.
- Обязателен канареечный тест: узнаваемые значения не встречаются в выводе, журнале, отчёте,
  экспорте (`docs/testing.md` §4).
- Перед PR — субагент `security-reviewer`.
