# Загрузка и установка бинарников

Порядок и ограничения — `docs/operations/updates.md`.

- Источники — закрытый список адресов в коде и строка в `docs/dev/dependencies.md` §5; только
  HTTPS; перенаправление на адрес вне списка — ошибка.
- Файл не исполняется и не устанавливается, пока не сверены суммы (SHA-256 и SHA-512 для Xray,
  SHA-256 для `xm`); архив из кэша сверяется заново.
- Распаковка: каждый путь остаётся в каталоге назначения; размер и число файлов ограничены.
- После распаковки — проверка ELF, архитектуры и ответа `xray version`.
- Переключение версии — только транзакцией с контролем и откатом; предыдущая версия не
  удаляется до успешного контроля.
- Ослабление любой из этих проверок — только через ADR.
- `install.sh`: только скачать, сверить, запустить `xm install`; тело — в функции, вызываемой
  последней строкой; логика установки в него не добавляется.
- На каждую проверку — тест с испорченным входом (`docs/testing.md` §3).
