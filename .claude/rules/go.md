# Код на Go

- **Границы**: импорты — по таблице `docs/architecture/repository.md` §3. Менеджеры не
  импортируют друг друга: нужное от соседа объявляется у себя интерфейсом потребителя, связывает
  `cmd/xm`.
- **Побочные эффекты** (процессы, файлы, systemd, сокеты, часы) — только через `platform`.
- **Изменение системы** — только внутри транзакции `app`
  (`docs/adr/0005-transactions-and-rollback.md`).
- **Один путь**: без запасных веток, деградированных режимов и вторых реализаций, если они не
  записаны в ADR. Нечем выполнить — вернуть ошибку.
- **Ошибки**: оборачивать с контекстом через `%w`; наружу — стабильный код контракта
  (`docs/architecture/interfaces.md` §2); `panic` не средство обработки ошибок.
- **Ожидание**: `context.Context` первым аргументом и таймаут у всего, что ждёт сеть или процесс.
- **Зависимости** — через конструктор; нет изменяемых глобальных переменных и `init` с
  побочными эффектами.
- **Вывод**: журнал — только через `logging`; печать в stdout — только в `cli`.
- **Ввод** проверяется по закрытому правилу до использования (`docs/security/policy.md` §5).
- **Сторонний импорт** — только после согласия владельца и строки в `docs/dev/dependencies.md`.
- Комментарий объясняет «зачем», а не «что». Объём правки равен задаче.
- Тесты — правило `tests.md`; перед коммитом — `bash scripts/check.sh`.
