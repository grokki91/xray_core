# Пакет platform

Единственное место побочных эффектов; его ошибки — это потерянный доступ и испорченные файлы.

- Процесс запускается массивом аргументов, без оболочки; имя программы — константа из закрытого
  списка; пользовательский ввод — только отдельным аргументом.
- У каждого процесса и сетевой операции — таймаут из контекста.
- Запись файла: временный файл в том же каталоге, права и владелец по манифесту
  (`docs/architecture/data-model.md` §1), `fsync`, затем `rename`.
- Секрет процессу — через stdin или файл; не аргументом и не переменной окружения.
- При записи и удалении не следовать по символическим ссылкам; удалять только пути манифеста.
- Различия между версиями ОС живут только здесь.
- Каждая операция есть и в настоящей, и в поддельной реализации; общий тест проверяет, что
  обе ведут себя одинаково в части, на которую опираются менеджеры.
- Изменение этого пакета — повод для субагента `security-reviewer`.
