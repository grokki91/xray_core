# Реестр зависимостей и инструментов

Всё внешнее, от чего зависит проект: модули Go, действия CI, инструменты проверки, вендорные
файлы, внешние адреса, к которым обращается `xm`. Правило: **нет строки здесь — нет зависимости**.

- Новая строка требует согласия владельца; в колонке «Согласовано» — дата и ссылка на PR или ADR.
- `scripts/check.sh` не пропускает изменение `go.mod`, `go.sum`, `.github/workflows/` и
  `web/vendor/` без изменения этого файла.
- Перед добавлением: чем не подходит стандартная библиотека; лицензия; кто сопровождает; сколько
  транзитивных зависимостей; как фиксируется версия. Анализ инструментов — [tooling.md](tooling.md).

## 3. Сборка, проверки, CI

Строки согласованы заранее; инструмент подключается в фазе из [tooling.md](tooling.md) §1 и до
этого в проверках не участвует.

| Имя | Вид | Зачем | Фиксация | Согласовано |
|---|---|---|---|---|
| GitHub Actions | CI | запуск `scripts/check.sh` на PR и `main` | действия — по хэшу коммита; права `contents: read` | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| Secret scanning и push protection | настройка репозитория GitHub | отклонение отправки с распознанными токенами | не требуется | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| gitleaks | сканер секретов, CI | секреты в дереве и истории | версия и сумма бинарника | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| govulncheck | сканер уязвимостей Go, CI | уязвимости в вызываемом коде; обращается к базе уязвимостей Go | версия модуля | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| staticcheck | анализ Go, CI | ошибки сверх `go vet` | версия модуля | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| shellcheck | анализ Bash, CI | `install.sh`, `scripts/`, хуки | версия и сумма бинарника | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |
| Dependabot | обновления, GitHub | предложения обновить действия и модули Go; без автослияния | файл настройки | 2026-11-14, [ADR-0016](../adr/0016-dev-tooling.md) |

## 5. Внешние адреса, к которым обращается `xm`

Заполняется с кодом (фазы 2–5): адреса релизов GitHub, DoH-серверы по умолчанию, контрольные
узлы диагностики, адрес для определения внешнего IP, тестовый адрес самопроверки. Каждый адрес — закрытый список в коде и
строка здесь.
