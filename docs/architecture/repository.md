# Структура репозитория

Что есть сейчас и что появится с кодом. Новый пакет в `internal/` обязан получить строку здесь —
это проверяет `scripts/check.sh`.

## 3. Правила зависимостей

| Пакет | Может импортировать |
|---|---|
| `cmd/xm` | всё |
| `cli`, `api`, `webui`, `bridge` | `app`, `contract` |
| `app` | менеджеры, `contract`, `store` |
| менеджеры (`core` … `monitor`) | `platform`, `store`, `redact`, `contract` |
| `store` | `platform`, `contract` |
| `platform`, `redact`, `contract` | только стандартную библиотеку |

- Менеджеры не импортируют друг друга; подпакеты менеджера (`config/preset`, `profile/export`,
  `diag/checks`) импортирует только их менеджер.
- `os/exec`, `net.Listen`, запись файлов вне временных каталогов тестов — только в `platform`.
- Правила проверяет тест графа импортов (появляется вместе с первым пакетом, фаза 1); до его
  появления — ревью субагентом `architecture-reviewer`.

## 4. Именование

- Имя пакета — одно слово в нижнем регистре, совпадает с каталогом.
- Идентификаторы проверок, пресетов, схем и кодов ошибок — латиница в нижнем регистре через
  точку или дефис: `xray.service.active`, `reality-xhttp`, `diag-report`, `preflight.foreign_install`.
- Документы и комментарии — на русском; идентификаторы, команды и сообщения коммитов — на английском.
