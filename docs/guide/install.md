## 1. Подготовка

- Ubuntu Server 22.04 или 24.04, x86_64, вход по SSH под root или пользователем с `sudo`.
- Установлены `curl` и `sha256sum` (в Ubuntu Server есть по умолчанию); загрузчик их не ставит.
- Порт 443/tcp свободен — или выберите другой флагом `--port`.
- Не закрывайте текущую сессию SSH до конца установки.

## 2. Установка

Загрузчик `install.sh` проверяет root и архитектуру, скачивает `xm` и `SHA256SUMS` из одного
выпуска, сверяет SHA-256, кладёт `xm` в `/usr/local/bin/xm` и запускает `xm install`
([ADR-0013](../adr/0013-distribution-and-bootstrap.md)). Не совпала сумма — установка отменена.

**В одну строку** — последний выпуск:

```bash
curl -fsSL https://github.com/grokki91/xray_core/releases/latest/download/install.sh | sudo bash
```

**Скачать, прочитать, запустить** — тот же загрузчик, но сначала его можно прочитать и проверить
происхождение сборки (нужен [GitHub CLI](https://cli.github.com/) на любой машине):

```bash
curl -fsSLO https://github.com/grokki91/xray_core/releases/latest/download/install.sh
```

```bash
less install.sh
```

```bash
gh attestation verify install.sh --repo grokki91/xray_core
```

```bash
sudo bash install.sh
```

**С фиксированной версией** — тег вида `vX.Y.Z` (здесь для примера `v0.0.1`):

```bash
curl -fsSL https://github.com/grokki91/xray_core/releases/download/v0.0.1/install.sh | sudo XM_VERSION=v0.0.1 bash
```

Флаги `xm install` передаются после `-s --`, все необязательны:

```bash
curl -fsSL https://github.com/grokki91/xray_core/releases/latest/download/install.sh | sudo bash -s -- --port 8443
```

| Флаг | По умолчанию |
|---|---|
| `--sni <домен>` | цель REALITY из закрытого списка, прошедшая проверку ([ADR-0035](../adr/0035-reality-target-candidates.md)) |
| `--address <адрес>` | адреса сервера по сетевым фактам; за NAT — внешний адрес |
| `--port <порт>` | 443 |

Если GitHub ответил 403 из-за лимита запросов без авторизации, задайте токен API в
`XM_GITHUB_TOKEN` ([ADR-0031](../adr/0031-github-api-token.md)): `sudo XM_GITHUB_TOKEN=… bash install.sh`.

## 3. Что делает установка

Только своё ([ADR-0036](../adr/0036-install-changes-only-own.md)): системный пользователь `xray`,
каталоги и файлы `xm`, официальный Xray-core с проверкой суммы, юнит `xray.service`, ключи и
конфигурация. Пакеты не ставятся, SSH не трогается, фаервол не включается.

- UFW активен — добавляется правило для порта Xray ([ADR-0041](../adr/0041-ufw-rule-in-install-transaction.md)).
- UFW не активен, а порт закрывают правила nftables или iptables, — они не меняются: итог
  называет факт и команду, которая откроет порт. Фаервол хостера установка не видит.
- Изменение идёт транзакцией: при сбое всё сделанное откатывается, код выхода 1.

## 4. Результат и профили

Установка заканчивается ссылкой VLESS первого профиля `profile-1` на каждый адрес сервера и QR
одной из них. Ссылка — секрет: передавайте её только по защищённому каналу. Отсканируйте QR
клиентом или вставьте ссылку; какие клиенты подходят — [compatibility.md](../compatibility.md).

```bash
sudo xm status
```

```bash
sudo xm add phone
```

```bash
sudo xm show phone
```

`xm list` — список профилей без секретов, `xm rm <имя>` — удалить профиль.

## 5. Повторный запуск и удаление

Повторный запуск той же команды ничего не меняет: код 0, «ничего не изменено», те же ссылки;
ключи не перевыпускаются. Флаг, расходящийся с установленным, — отказ с кодом 2.

```bash
sudo xm uninstall
```

убирает службу, юнит, правило UFW `xm` и бинарники; состояние и снимки остаются.
`sudo xm uninstall --purge` удаляет и их вместе с пользователем `xray` после ввода слова `purge`
([ADR-0042](../adr/0042-uninstall-ordered-idempotent.md)).

## 6. Если не получилось

| Код | Что значит | Что делать |
|---|---|---|
| 1 | операция не удалась, откат выполнен | прочитать сообщение: в нём причина и следующий шаг |
| 2 | неверные аргументы | сверить флаги с таблицей §2 |
| 3 | предусловия: не root, не та ОС, занят порт, чужая установка Xray | исправить причину из сообщения; чужую установку `xm` не трогает |
| 5 | откат не удался | выполнить шаги из сообщения точно по порядку |

Клиент не подключается при успешной установке — проверьте порт у хостера и в фаерволе сервера;
это предположение, а не факт: подтвердить его может только проверка снаружи.
