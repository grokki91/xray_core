# ADR-0020: Стенд L3 с настоящим Xray

- Статус: Принято
- Дата: 2026-11-16

## Контекст

Тесты L3 ([testing.md](../testing.md) §2) запускают настоящий бинарник Xray. `platform.Real`
запускает `xray` только из `/usr/local/lib/xm/core/<версия>/xray` — тесту нужен root и чужая
машина; `platform.Fake` отвечает обработчиками. Шаг 3b фазы 2 требует помощника вне пакетов
менеджеров, архив с проверкой суммы и кэшем по версии и задание CI.

## Решение

- Помощник — `internal/platform/xraytest`: закреплённые версии и SHA-256 архива
  `Xray-linux-64.zip`, кэш `<UserCacheDir>/xm-test/xray/<версия>/` с повторной сверкой;
  неверная сумма — провал теста. Загрузку передаёт тест: `platform.Net.Get` с узлами
  `github.com` и `release-assets.githubusercontent.com` — второго загрузчика нет, а подпакет
  `platform` не импортирует `platform`. Импортируется только из `_test.go` (тест границ).
- `Fake.RunUnderRoot(program)` запускает настоящий файл программы под корнем подделки тем же
  путём, что `Real.Exec` (окружение, группа процессов, пределы); аргумент, начинающийся с `/`,
  получает префикс корня по правилу путей `FS` (неочищенный — `ErrPath`). Root не нужен, контракт `Platform` не меняется.
- Версии — нижняя и верхняя границы проверенного диапазона ([compatibility.md](../compatibility.md) §2).
- Тесты L3 — под тегом сборки `l3`, имена `TestL3…`; обычный `go test` и `scripts/check.sh`
  сеть не трогают. Задание `l3` в `check.yml` качает архивы каждый прогон, без кэша CI.
- Выбор владельца 2026-11-16 (вопросы к шагу 3b фазы 2).

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Пакет `internal/xraytest` своим слоем | новая строка таблицы слоёв ради помощника тестов |
| `platform.Real` под root в CI | локально без root не запускается; тест трогает систему |
| Свой HTTP-загрузчик в `xraytest` | второй путь рядом с `Net.Get`: свои проверки адресов и очистка ошибок |
| `actions/cache` для архивов | новая зависимость CI ради ~32 МБ за прогон |
| L3 в обычном `go test` | сеть при каждом коммите через хуки |

## Последствия

- Новая версия в проверенном диапазоне — строка в `xraytest` с суммой из `.dgst`, сверенной с
  загрузкой, и факт в [compatibility.md](../compatibility.md) §2.
- Подмена аргументов по префиксу `/` годится для путей; аргумент-значение с ведущим `/`, не
  являющийся путём, исказится — пересмотреть, если такой понадобится.
