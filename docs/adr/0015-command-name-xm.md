# ADR-0015: Имя команды — `xm`

- Статус: Принято
- Дата: 2026-11-14

## Контекст

В `grokki91/xray` уже есть менеджер `xm` на Bash, и `xray_client` вызывает на узле именно
`xm bridge …`. Имя команды фиксируется до первого кода: от него зависят путь бинарника,
README, `install.sh` и сообщения об ошибках.

## Решение

- Команда нового менеджера — `xm`; бинарник ставится в `/usr/local/bin/xm` (ADR-0013).
- Установка предшественника и новая установка на одном сервере не поддерживаются.
- Миграция установки предшественника, контракты моста и имя репозитория решаются отдельно
  ([вопрос Q4](../open-questions.md)).

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Новое имя (например, `xmgr`) | `xray_client` пришлось бы менять ради имени; две установки на одном сервере всё равно несовместимы |

## Последствия

- Мост для `xray_client` возможен без смены вызываемой команды.
- Пересмотреть, если понадобится держать обе установки на одном сервере.
