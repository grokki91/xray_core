# ADR-0012: Уровни поддержки ОС

- Статус: Ждёт решения (Q8)
- Дата: 2026-11-13

## Контекст

Целевая платформа — Ubuntu Server на x86_64. Версии 22.04 и 24.04 — основные, 26.04 нужно
проверять, 20.04 — отдельный унаследованный случай. Обещать одинаковое качество везде — значит
не проверять нигде.

## Решение (рекомендация)

| Уровень | ОС | Обязательства |
|---|---|---|
| Основной | Ubuntu 22.04, 24.04 | системные тесты на каждом выпуске |
| Проверяемый | Ubuntu 26.04 | проверка перед выпуском, расхождения документируются |
| Унаследованный | Ubuntu 20.04 | установка только с явным флагом и предупреждением; без тестов и обещаний |
| Вне поддержки | всё остальное | остановка на проверке предусловий |

- Различия между ОС сосредоточены в `platform` и в наборе директив юнита; остальные пакеты о
  версии ОС не знают.
- Уровень определяется проверкой предусловий и показывается в `xm status`.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Поддерживать 20.04 наравне | systemd 245 не знает части директив изоляции — нужна отдельная ветка настроек и свои тесты для ОС без стандартной поддержки |
| Отказаться от 20.04 совсем | допустимо; флаг сохраняет возможность без затрат на сопровождение |
| Debian и другие дистрибутивы сразу | каждая ОС — строка в матрице системных тестов; добавляется по запросу |

## Последствия

- Матрица системных тестов — две ОС; третья добавляется, когда появится её образ.
- Пользователь 20.04 получает работающую, но слабее изолированную службу и знает об этом.
- Добавление ОС или архитектуры — новая строка в [compatibility.md](../compatibility.md) и
  системный тест, без изменения архитектуры.
