# ADR-0014: Экосистема инструкций для LLM

- Статус: Принято
- Дата: 2026-11-13

## Контекст

Проект разрабатывается сессиями LLM, которые не помнят друг друга. Каждая должна понять
архитектуру, границы, правила безопасности и критерии готовности, не читая всё подряд: контекст
ограничен, а лишние инструкции ухудшают следование нужным.

## Решение

- **Один вход**: `AGENTS.md` — правила, верные в каждой сессии, и указатель «что загрузить
  когда». `CLAUDE.md` подключает его и описывает только особенности Claude Code.
- **Пять уровней загрузки**: всегда → по пути файла → по типу задачи → документ по ссылке →
  отдельный контекст субагента ([ai-ecosystem.md](../dev/ai-ecosystem.md) §2).
- **Пределы размера** у каждого уровня, проверяемые `scripts/check.sh`.
- **Один факт — одно место**: правило и скил ссылаются на политику в `docs/`, а не пересказывают.
- **Изменчивое — вне префикса**: состояние работ и датированные факты не попадают в `AGENTS.md`.
- **Проверяемое — автоматикой**: обязательные проверки собраны в `scripts/check.sh`; хуки
  вызывают её в нужные моменты.
- Новый элемент экосистемы появляется при повторяющейся потребности, а не заранее.
- Принципы автономности агента, «одного пути» и объёма задачи в `AGENTS.md` взяты из
  приложенных владельцем слайдов; пункты, привязанные к чужому окружению (работа вне песочницы,
  личный файл с ключами), не перенесены.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Один большой файл инструкций | весь объём в каждом запросе; важное тонет |
| Внешняя система спецификаций (OpenSpec и аналоги) | второе дерево документов и новый процесс до появления кода ([tooling.md](../dev/tooling.md) §4) |
| Правила только в документации для людей | агент не узнаёт о них в нужный момент; нет автоматической проверки |
| Инструкции на английском | дешевле по токенам, но их читает и правит владелец (вопрос Q11) |

## Последствия

- Инструкции — часть кода: меняются в той же правке и проходят те же проверки.
- Хуки работают только в Claude Code; гарантия для остальных — CI после согласия владельца.
- Пределы размера придётся защищать: рост инструкции — сигнал вынести подробности в `docs/`
  или `references/`.
