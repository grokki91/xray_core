# ADR-0037: Лицензия MIT

- Статус: Принято (владелец, 2026-11-23; Q10)
- Дата: 2026-11-23

## Контекст

Репозиторий публичный, файла лицензии нет: формально код нельзя использовать. Лицензия нужна
до первого выпуска. `xm` не содержит кода Xray-core и не линкуется с ним (инвариант 1).

## Решение

- Код репозитория — под MIT; текст — файл `LICENSE` в корне.
- Xray-core ставится отдельным официальным бинарником под своей лицензией (MPL-2.0); `xm` его
  не распространяет внутри своего выпуска.
- Зависимость Go принимается, если её лицензия совместима с MIT; лицензия — строка в
  [dependencies.md](../dev/dependencies.md).

## Альтернативы

| Вариант | Почему нет |
|---|---|
| MPL-2.0, как у Xray-core | файловый копилефт не нужен: кода Xray в `xm` нет; MIT проще для пользователя |

## Последствия

- Любой может использовать и менять код с сохранением уведомления.
- Пересмотреть, если в `xm` войдёт чужой код с иной лицензией.
