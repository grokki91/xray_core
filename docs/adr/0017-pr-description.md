# ADR-0017: Описание PR без подписи ассистента

- Статус: Заменено ADR-0018
- Дата: 2026-11-15

## Контекст

Сессии LLM по умолчанию дописывают в тело PR подпись ассистента и ссылку на сессию. В `xray` и
`xray_client` такой подписи нет. Владелец решил перенести это правило сюда (Q12).

## Решение

- Тело PR заполняется по `.github/PULL_REQUEST_TEMPLATE.md`. Подписи ассистента и ссылки на
  сессию в нём нет.
- Правило записано в `AGENTS.md` (раздел «Порядок работы») и в шаблоне PR. Оно действует
  сильнее настроек атрибуции в инструменте агента.
- Сообщений коммитов правило не касается.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Оставить подпись, как делает инструмент | расходится с соседними репозиториями; владелец выбрал единое правило |
| Проверять тело PR хуком `publish-guard.sh` | шаблонные строки инструмента меняются; правила в инструкциях достаточно, пока нарушений нет |

## Последствия

- Описание PR состоит только из разделов шаблона.
- Если подпись появится вопреки правилу, следует добавить проверку в `publish-guard.sh`.
