# ADR-0035: Цель REALITY — список кандидатов с живой проверкой

- Статус: Принято (владелец, 2026-11-23; Q3, вариант B)
- Дата: 2026-11-23

## Контекст

REALITY нужен чужой сайт-цель с TLS 1.3 и h2. Установка должна проходить без вопросов
(цель фазы 4), а `--sni` в ADR-0025 обязателен до решения Q3.

## Решение

- В коде `network` — закрытый список кандидатов (до 10 имён); каждое имя — строка с датой
  проверки в [compatibility.md](../compatibility.md).
- `xm install` без `--sni` проверяет кандидатов с сервера одним соединением к `<имя>:443`:
  TLS 1.3, ALPN h2, группа X25519MLKEM768, действительный сертификат на это имя, адрес цели не
  частный и не петлевой. Из прошедших выбирается кандидат с наименьшим временем рукопожатия.
- `--sni <имя>` заменяет список: имя проходит те же проверки; провал — отказ с причиной.
- Ни один кандидат не прошёл — отказ установки с причиной по каждому и подсказкой `--sni`.
- Выбранная цель сохраняется в состоянии; повторная установка её не перевыбирает.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| A. Обязательный `--sni` | нарушает «установка без вопросов» |
| C. Поиск соседей по сети (свой сканер, RealiTLScanner) | активное сканирование чужих адресов с VPS — риск жалоб и блокировки сервера; сторонний бинарник или заметный объём кода |
| D. Свой домен и сертификат | нужен домен; выпуск сертификатов и веб-сервер — отдельная подсистема |

## Последствия

- Цель обычно не из сети сервера, популярные кандидаты общие для многих установок — известный
  признак; насколько он важен, не проверено. Обход блокировок не обещается.
- Список устаревает: кандидат, переставший проходить проверку, удаляется правкой с датой.
- Пересмотреть, если владелец попросит поиск цели рядом — отдельной командой после MVP (C).
