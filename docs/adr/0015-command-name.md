# ADR-0015: Имя команды `xm`

- Статус: Принято
- Дата: 2026-11-14

## Контекст

Имя команды входит в каждый документ, юнит, путь и в вызовы со стороны `xray_client`. Его нужно
закрепить до первой строки кода (Q4, часть 1). В `grokki91/xray` уже есть Bash-менеджер `xm`, с
которым работает `xray_client`.

## Решение

Команда нового менеджера — `xm`. Миграция установки предшественника, мост для `xray_client` и
имя репозитория этим решением не затрагиваются и остаются в Q4
([open-questions.md](../open-questions.md)).

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Новое имя | `xray_client` и привычка владельца завязаны на `xm`; выигрыш — только различимость с предшественником, а совместной установки на одном сервере всё равно нет |

## Последствия

- Две установки с одним именем команды на одном сервере невозможны; `xm install` рядом с
  предшественником решается вместе с вопросом о миграции (Q4).
- Пересмотреть, если владелец решит поддерживать совместную работу с предшественником.
