# ADR-0040: Цель REALITY не перенаправляет корень на другое имя

- Статус: Принято (владелец, 2026-11-24)
- Уточняет: [ADR-0035](0035-reality-target-candidates.md)
- Дата: 2026-11-24

## Контекст

Upstream требует от цели: домен не используется для редиректа, допустим редирект основного домена
на `www` ([compatibility.md](../compatibility.md) §2). В проверке ADR-0035 этого критерия нет.

## Решение

- Проверка цели — по-прежнему одно соединение: после рукопожатия по тому же соединению HTTP/2
  отправляется один запрос `HEAD /` с `Host` = имени цели, без тела и cookie.
- Критерий пройден, если ответ не 3xx, или 3xx с `Location` на то же имя (относительный путь,
  схема `https`). 3xx на другое имя или другую схему — провал с причиной; ответ не получен в срок —
  провал «не проверено».
- Ответ читается только до заголовков, с пределом размера; тело не читается.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Не проверять | цель с редиректом нарушает требование upstream |
| Отдельное соединение для HTTP | второе соединение к чужому узлу без нужды |
| Следовать по цепочке редиректов | лишние запросы; достаточно первого ответа |

## Последствия

- К цели уходит один HTTP-запрос после рукопожатия; раньше — только рукопожатие.
- Кандидат, перенаправляющий корень на другое имя, выпадает из выбора.
