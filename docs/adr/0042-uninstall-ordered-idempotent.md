# ADR-0042: `uninstall` — упорядоченные идемпотентные шаги без отката

- Статус: Принято
- Дата: 2026-11-24

## Контекст

ADR-0005 требует ADR для сценария, который каркас транзакции не откатывает. Удаление уничтожает
то, к чему откат вернулся бы (бинарники, юнит, при `--purge` — состояние и снимки); хранить их
копии до конца ради отката — второй путь и лишние файлы вне манифеста.

## Решение

- `xm uninstall [--purge]` — не транзакция. Под блокировкой: откат незавершённой транзакции
  (пока ядро на месте), проверка «установлен» (есть состояние) и «юнит наш»; чужой юнит — отказ
  до всякого изменения.
- Шаги в постоянном порядке: снимок (только без `--purge` и пока ядро на месте) → остановка
  службы → юнит → правило UFW по метке (ADR-0041) → бинарники Xray и `xm` → с `--purge`
  конфигурация Xray, `/var/lib/xm`, `/run/xm`, пользователь `xray` (`userdel`) и последним
  `/etc/xm`.
- Отсутствующий предмет шага — не ошибка. Сбой шага — код 1; повтор команды доводит удаление:
  состояние уходит последним, поэтому повтор видит установку.
- Удаляются только корни манифеста (data-model.md §1) — `security.Remove`; дерево — через
  `platform.FS.RemoveTree` без перехода по ссылкам.
- Уточнение ADR-0041: `network.RevokePort` вызывает ещё `app.Uninstall` по метке, вне
  транзакции; снятие несуществующего правила — код 0, поэтому повтор безопасен.
- Удаление по манифесту принадлежит `security` — владельцу манифеста, а не `core` и `backup`.
- `--purge` подтверждается вводом слова `purge`; `--yes` заменяет только ввод.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Транзакция с откатом к снимку | копии бинарников и юнита до конца удаления; откат удаления, которое владелец заказал, ему не нужен |
| Пользователь `xray` не удаляется никогда | след после `--purge` |
| Обход дерева в вызывающем через `ReadDir` и `Remove` | второй обходчик вне `platform`, ссылки и каталоги — снова в каждом потребителе |

## Последствия

- Прерванное удаление оставляет частичную установку до повтора `xm uninstall`; `xm install` её
  не чинит.
- Без `--purge` `xm` тоже удаляется: `--purge` позже — только после повторной загрузки `xm`.
- Пересмотреть, если удаление получит шаги, которые нельзя повторить безопасно.
- Метки «пользователь создан xm» нет: `--purge` удалит и `xray`, заведённого до `xm`.
